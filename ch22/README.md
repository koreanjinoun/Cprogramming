# 실습과제1
* **구조체가 필요한 이유:** 서로 다른 자료형 변수를 묶어서 저장할 수 있다.
* **배열과 공통점과 차이점:** 둘 다 여러개의 데이터를 묶음으로 처리가능하지만 배열은 하나의 자료형만 처리 가능하다.
* **기본자료형과 구조체의 차이:** 기본적으로 제공되는 기본자료형과 달리 구조체는 직접 정의하는 자료형이다.
* **구조체의 정의와 구조체 변수 선언의 의미:** 구조체는 새로운 자료형의 정의를 하며 구조체 변수 선언은 구조체 변수를 선언하고 메모리를 할당한다.
