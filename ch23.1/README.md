# 실습과제1
### 1. 구조체가 왜 필요한지 설명하시오.
* 서로 다른 자료형의 데이터들을 하나의 단위로 묶어 체계적으로 관리할 수 있다.
### 2. 공용체가 왜 필요한지 설명하시오.
* 여러 멤버가 하나의 메모리 공간을 공유하게 하여 메모리를 절약할 수 있다.
### 3. 열거형이 왜 필요한지 설명하시오.
* 직관적인 이름을 부여하여 코드의 가독성을 높일 수 있다.
